# Retail Sales & Customer Analytics Using MySQL

## Project Overview
This project analyzes retail customer, product, and order data using MySQL. The goal is to understand sales performance, customer spending, product performance, and order status.

## Tools Used
- MySQL
- MySQL Workbench

## Database Tables
- **Customers:** Customer details and signup dates
- **Products:** Product names, categories, and prices
- **Orders:** Order dates and order statuses
- **Order Items:** Products, quantities, and unit prices for each order

## SQL Concepts Used
- Database and table creation
- INSERT and SELECT statements
- WHERE, ORDER BY, and LIMIT
- Aggregate functions: SUM() and COUNT()
- GROUP BY
- INNER JOIN
- CASE statements
- Date formatting using DATE_FORMAT()

## Business Analysis
1. Calculated overall sales.
2. Identified products with the highest sales.
3. Analyzed customer spending.
4. Counted orders by status.
5. Calculated completed-order sales.
6. Analyzed cancelled-order value.
7. Classified products by sales amount.
8. Analyzed monthly sales.

## Key Learning
This project provided hands-on practice in writing SQL queries, combining multiple tables, calculating sales metrics, and answering basic business questions using data.
